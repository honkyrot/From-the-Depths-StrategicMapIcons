# StrategicMapIcons

This mod adds icons into the strategic map for the game [From the Depths](https://store.steampowered.com/app/268650/From_the_Depths/).

## Features

- Vector-based icons for most craft types.
- Automatic role detection for craft, with the ability to override the role manually.
- Material fleet costs are shown under the icon if large.

## Notes

Automatic detection is not perfect, and may misclassify some craft.

Built for version 4.3.4.1
